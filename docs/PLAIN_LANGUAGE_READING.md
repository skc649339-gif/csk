# CSK V2 本地白话解读

## 使用

完成起盘或打开历史记录后，点摘要卡片「查看白话解读」，也可点导航「白话解读」。十个主题包含整体、性格、事业、财运、感情、十二宫、四化、十年大限、流年边界和综合建议。没有命盘时先提示起盘或打开记录，不用空白模板代替分析。

每节有一句话总结、详细解读、可展开的命盘依据和实际生活建议。十二宫、大限可选择。底部术语和来源可展开。「复制完整解读」复制全部章节；浏览器拒绝时展示只读文本框供手动选择。解读不含姓名、出生地址等身份字段，但仍可能反映私人偏好，请自行决定分享对象。

首次联网并完成核心缓存后，规则、文字和阅读页面随已有 PWA 核心资源离线使用。用户主动点击经典来源链接需要联网。不会接入 AI、上传生辰、增加账户或额外写入本地存储；报告不作为新历史格式持久化。

## 字段与计算边界

| 资料 | 规则 |
| --- | --- |
| 十二宫 | 兼容原引擎「财帛」「官禄」「仆役」等无“宫”后缀名称；内部标准化只用于查找，绝不改写原始对象。 |
| 命宫/身宫 | 按 mingGongBranch/shenGongBranch，核对可选布尔标记。 |
| 主星 | 十四星全部覆盖；已实现20组实际同宫组合，其他组合合并两种特质并结合宫位、辅曜、四化等条件，不宣称完整格局成立。 |
| 亮度 | 只取快照原值，庙旺与不陷等仅调节表达条件，不作吉凶评分；缺项明确说明。 |
| 空宫 | 由实际 type=major 判断，用 branch+6 的真实对宫主星作间接参考。借星注记过时会提示，绝不把对宫四化搬到本宫。 |
| 三方四正 | 地支 +4、+8 与 +6；逐个列出真实宫位、主星及四化，作为背景，不虚构星曜位置。 |
| 四化 | 生年标记、自化和大限四化分开。自化必须能在本宫回查星曜；大限四化缺项不补算，无法定位星曜则标记限制。 |
| 年龄/大限 | 只读快照实际 startAge/endAge；不将今天的年份混入历史记录，不强行更新当前区间。 |
| 流年 | 完整推断未支持。原页的年干四化叠加不足以生成完整年度事件报告，首版不编造流年。 |

## 知识库与出处

`lib/interpretation/knowledge.ts` 保存传统概念索引、十四星表达素材、20组同宫组合、12宫生活语境、4种四化含义及7组术语。`engine.ts` 根据实际盘面组合并输出规则 ID、来源 ID、宫支与星名，便于人工复核。

- 《紫微斗数全书》卷一〈太微赋〉、〈斗数准绳〉及〈诸星问答论〉：https://zh.wikisource.org/wiki/紫微斗數全書/卷一
- 卷二十二宫主题：https://zh.wikisource.org/wiki/紫微斗數全書/卷二
- 卷三行限主题：https://zh.wikisource.org/wiki/紫微斗數全書/卷三
- `lib/ziwei/types.ts`：实际结构化盘面；这一层是数据事实。
- 本版生活化表达、组合取舍、边界提醒及行为建议：CSK 编辑性整理，不冒称古籍逐字原文，不具有科学预测的证明。

本地旧古籍精选含有现代整理语句，本版不复制它们作为“原文”，也未复制倪师 CC BY-NC-SA 解说。经典的疾病、寿夭、性别和阶级偏见不转写成对用户的断语。不判断健康诊断、投资收益、伴侣品行、生育情况或必然事件。

20组同宫组合：紫微天府、紫微七杀、紫微破军、紫微贪狼；天机太阴、天机巨门、天机天梁；太阳太阴、太阳巨门；武曲天府、武曲贪狼、武曲七杀、武曲破军；天同太阴、天同巨门、天同天梁；廉贞天相、廉贞七杀、廉贞破军、廉贞贪狼。只有实际同宫或真实对宫借入时触发。

辅曜分六组：协助（辅弼魁钺）、文书表达（昌曲）、积累（禄存）、行动环境（天马）、节奏摩擦（羊陀火铃）、预期与资源落差（空劫）。不存在的星不引用；其余杂曜列为未独立解释。

## 校验、测试与维护

先调用既有运行时快照校验，另核对名称唯一、星曜唯一、身命/空宫/对宫标记及十年区间。必需结构不可靠时停止生成并提示保留原记录，不修改或删除数据。`interpretChart` 是纯读取函数，没有网络、存储或当前时间依赖；`readingToText` 提供可复制文本。

`npm run test:reading` 覆盖多盘依据回查、20组合与14星、身命同异、空宫与借星、亮度/四化缺项、错误嵌套、日期边界、四种闰月策略、只读性、确定性与旧备份兼容；该套件也已加入 `npm run test:local`，生产工作流保持原样。

维护新规则时：给出准确触发条件与来源层次，输出可机读依据，增加一条能命中及一条不能命中的测试，保持既有断言和快照不变。不得用当前年份填补缺失行限，不能以个别示例证明整个传统体系正确。进一步扩展前需人工审校文案与流派口径；未来 AI 功能须另行设计后端、隐私同意和本地降级，本轮没有 API Key 或 AI 调用。

真实 iPhone Safari 与主屏幕 PWA 的 V2 验收尚未执行；桌面 Chromium 和桌面 WebKit 的结果单独报告。此文档不代表发布授权。
